# Лабораторная работа 1: Работа с сокетами в Python

## Описание

Этот проект содержит решения пяти заданий по работе с сетевыми сокетами в Python.

## Задание 1: UDP клиент-сервер для обмена сообщениями

**Описание:** Реализован простой UDP клиент и сервер для обмена сообщениями "Hello, server" / "Hello, client".

**Файлы реализации:**
- `task1/client.py` - UDP клиент
- `task1/server.py` - UDP сервер

**Запуск:**
1. Запустите сервер: `python server.py`
2. В другом терминале запустите клиент: `python client.py`
3. Введите сообщение в клиенте

## Задание 2: TCP клиент-сервер для расчета площади параллелограмма

**Описание:** TCP приложение для вычисления площади параллелограмма по формуле S = основание × высота.

**Файлы реализации:**
- `task2/client.py` - TCP клиент с интерфейсом для ввода данных
- `task2/server.py` - TCP сервер для обработки расчетов

**Запуск:**
1. Запустите сервер: `python server.py`
2. В другом терминале запустите клиент: `python client.py`
3. Введите основание и высоту через запятую

## Задание 3: Простой HTTP сервер

**Описание:** HTTP сервер, который обслуживает HTML-страницу из файла index.html.

**Файлы реализации:**
- `task3/server.py` - HTTP сервер
- `task3/index.html` - HTML страница

**Запуск:**
1. Запустите сервер: `python server.py`
2. Откройте браузер и перейдите на http://localhost:8080

## Задание 4: Многопользовательский чат

**Описание:** TCP чат-сервер с поддержкой нескольких пользователей, использующий потоки для одновременной обработки подключений.

**Файлы реализации:**
- `task4/server.py` - Чат-сервер
- `task4/client.py` - Чат-клиент

**Запуск:**
1. Запустите сервер: `python server.py`
2. Запустите несколько клиентов в разных терминалах: `python client.py`
3. Введите имя пользователя и начинайте общаться

## Задание 5: Веб-сервер для управления оценками

**Описание:** HTTP сервер для обработки GET и POST запросов, позволяющий добавлять оценки по дисциплинам и просматривать их в виде HTML страницы.

**Файлы реализации:**
- `task5/server.py` - Веб-сервер
- `task5/Index.html` - Шаблон HTML страницы
- `task5/grades.txt` - Файл для хранения оценок

**Функциональность:**
- GET / - отображает все оценки
- POST /add - добавляет новую оценку

**Запуск:**
1. Запустите сервер: `python server.py`
2. Откройте браузер и перейдите на http://localhost:8085

## Требования

- Python 3.6+
- Все задания используют только стандартную библиотеку socket
- Для многопользовательского чата используется threading
